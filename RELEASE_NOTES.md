# Release Notes

Latest release: **v2.9.0 Fit Analysis Reviewer Experience**

v2.9.0 makes semantic-mode fit analysis visible in the framework-free frontend demo with reviewer-friendly sections, readable badges, evidence snippets, rationales, and a copyable fit-review summary.

## Latest Highlights

- Added frontend rendering for semantic-mode `fit_summary`, matched requirements, and gaps.
- Added readable badges for requirement type, priority, matched confidence, and gap evidence support.
- Added inline evidence snippets for matched requirements and rationale text for reviewer context.
- Sorted semantic-mode gaps so high-priority gaps appear first.
- Added Copy Fit Review for a browser-only summary of score, fit summary, top matches, top gaps, matched confidence, and gap evidence-support indicators.
- Kept keyword-only behavior, backend scoring, API response shape, infrastructure, workflows, Lambda runtime, and dependencies unchanged.
